Q1.1)

Une classe utilitaire est une classe CSS qui permet d’appliquer rapidement un style précis à un élément HTML. Par exemple, mt-3 ajoute une marge en haut et text-center centre le texte. Elle sert principalement à modifier l’apparence d’un élément.



Un composant est un élément d’interface réutilisable qui regroupe plusieurs éléments HTML et styles pour remplir une fonction précise. Par exemple, une navbar est une barre de navigation et une card est une carte qui présente du contenu. Certains composants nécessitent du JavaScript pour gérer les interactions, tandis que d’autres sont purement visuels.

Dans Bootstrap 5, col-md-8 définit la largeur d’une colonne dans une grille de 12 colonnes.



col : désigne une colonne.



md : s’applique aux écrans moyens et plus grands, à partir de 768 px.



8 : la colonne occupe 8 colonnes sur 12, soit 66,67 % de la largeur disponible.



col-md-8 : occupe environ 66,67 % de la ligne.



col-md-4 : occupe environ 33,33 % de la ligne.





Dans Bootstrap 5, fw-bold permet de mettre le texte en gras (font-weight: bold).



Autres classes fw-\*

Classe      Rôle



fw-light    Texte fin



fw-normal   Texte normal



fw-medium   Texte moyennement épais



fw-semibold Texte semi-gras



fw-bold     Texte gras



fw-bolder   Épaisseur supérieure à celle de l’élément parent



fw-lighter  Épaisseur inférieure à celle de l’élément parent



À retenir : fw signifie font-weight (épaisseur du texte) et bold signifie « gras ».







Dans Bootstrap 5, bg-body-tertiary applique une couleur d’arrière-plan secondaire à un élément. La couleur exacte dépend du thème utilisé (clair ou sombre).



À retenir

bg = background (arrière-plan).



body = couleur liée au fond général du site.



tertiary = variante de couleur secondaire.

Classe          Rôle
